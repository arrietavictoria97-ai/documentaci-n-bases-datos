# Portal de documentación de bases de datos

Bienvenido a este portal de aprendizaje, diseñado para estudiantes con conocimientos básicos de bases de datos.

## Elige tu instructivo

-   :material-table-large: **MySQL (relacional)**

    Abre un instructivo desde el menú lateral, sigue los pasos en orden y copia los comandos desde los bloques de código. Los comandos requieren un entorno Ubuntu apropiado; no se ejecutan en esta página.
